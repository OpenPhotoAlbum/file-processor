## System Overview

### What This System Does
- **Processes photos and videos** with metadata extraction
- **Adds GPS and landmark information** using multiple data sources  
- **Organizes files** with intelligent deduplication
- **Preserves all original data** with zero data loss guarantee
- **Provides rich metadata** for searching and browsing

### What Makes It Special
- **Production-grade system** - Handles 150k+ photos efficiently
- **Zero data loss** - All processing is non-destructive
- **Rich enrichment** - Recreation.gov, GNIS, National Parks integration
- **Heritage photo support** - Special handling for historical photos
- **Database-backed** - Fast queries and comprehensive metadata
