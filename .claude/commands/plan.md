# Plan Command
Create a plan for something to work together on.

## Purpose
To generate documentation for a plan to implement, either now or later.

## Steps

Do not start any work on this plan at all. The idea is only to work together on planning and not act on any of it yet. Consider this whole file first before starting on Step 1.

1. **Check the Plan Idea**
   ```bash
   echo $ARGUMENTS
   ```

2. **Get Initial Context and Save Plan**
    - Consider what I am asking provided in my statement, and really think about it.
    - Use the MCP tool from mcp-project-context called search_codebase

3. **Simple Start**
    - After gaining some context, take another minute to think some more on it
    - Ask me any questions you feel could help work through this plan

3. **Collaboration**
    - Identify aspects of the plan that I may not have yet thought about
    - As we chat together, continue to provide an updated document for me to review
    - Make sure we consider a testing strategy for this plan (if needed)
    - Be verbose with your output
    - Ensure when you send your first draft to me for review, you add at the end how to "use" whatever the feature is we are discussing.
    - See if there is already an existing, related plan in ./plans.
    - If there isn't a plan there, lets create a new one there and update it as we work through coming up with the final plan

4. **Wrap Up**
    - After I agree on the plan, make sure you document it in the ./plans
    - Commit the plan to github
    - Ask me if we should start on it now, or look into something else.

## Success Criteria
- ✅ Plan created in ./plans/{name}.md
- ✅ The plan.md is committed into github
- ✅ Testing strategy was talked about and documented
